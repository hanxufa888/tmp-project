# チェック項目No.
CHK-124

# チェック項目
注記記号（"※"＋"数字"など）の追加・変更・削除に対し、対応する注記文章の記載漏れ・削除漏れ、および注記記号と注記文章内容との整合性を確認する。

# チェック判定仕様
- 仕様変更点に対して、注記記号が追加された場合は観点Aを実施し、変更された場合は観点AとBを実施し、削除された場合は観点Bを実施すること。
- 注記記号とは仕様書内の文章に対して、補足説明や注意事項、制約条件が存在することを示す符号で、「※」記号＋数字(アラビア数字/ローマ数字)で構成される。なお「※」記号のみの場合は本チェック対象とはしない。(注記記号とは見なさない)
  例：「〇〇受信時※1は、△△すること」の「”※1”」や、「□□条件成立※ⅰ」の「"※ⅰ"」
- 注記文章とは注記記号に対応した補足説明や注意事項、制約条件の説明文章を指し、注記記号と対を成す構成となっている。注記記号の後ろに説明文章を記載した形式で表現される。
  例：「※1 詳細は●●仕様書を参照すること」や、「※ⅰ条件成立中は◇◇表示を継続すること」

## 観点A：注記記号が追加、変更された場合
- 追加された注記記号もしくは変更後の注記記号に対して、当該注記記号が付与された表・表示ブロック内に、対となる注記文章が存在しない場合は、「問題あり」と判断する。
- 追加された注記記号もしくは変更後の注記記号に対して、当該注記記号が付与された表・表示ブロック内に、対となる注記文章が存在する場合は、注記記号が付与されている個所の文章と、対となる注記文章を比較し、記載内容の整合が取れていれば「問題なし」、不整合の場合は「問題あり」と判断する。

## 観点B：注記記号が変更、削除された場合
- 変更前の注記記号に対する注記文章、もしくは削除された注記記号に対する注記文章が、当該注記記号が付与されていた表・表示ブロック内に存在しない場合は、「問題なし」としてチェックを終了する。
- 変更前の注記記号に対する注記文章、もしくは削除された注記記号に対する注記文章が、当該注記記号が付与されていた表・表示ブロック内に存在する場合は、その注記文章に対応する注記記号が当該表・表示ブロック内に記載されているかを確認する。
  記載されている場合は「問題なし」、記載されていない場合は注記文章の削除漏れとして「問題あり」と判断する。

# チェック項目No. 
CHK-111

# チェック項目
【機能有無判定結果など、MET記憶がある場合】
RAM保持/不揮発性メモリ保持、いずれであるかが記載できているか？
原則、不揮発性メモリ記憶対象は”法規対象”か”機能安全対象”のみ。
(SWに関しては標準が不揮発性メモリ保持であるため、それで良ければ記載不要)

# チェック判定仕様
1. 機能有無判定処理が記載されている場合、記憶処理が記載されているか確認する。
 　以下の例のような記載があれば「問題なし」としてチェックを完了する。記載がない場合は手順2.に進む。
 　`RAM保持`、`+B-ON中も保持`、`+B保持`、`不揮発性メモリ保持`、`不揮発性メモリにて記憶`、`不揮発性メモリ保持要否`

2. クリア条件として、以下の例のような記載があれば「問題なし」とする。
   `+B-OFF時`、`メータスリープ時`
   クリア条件の記載がない場合、またはクリア条件に`ダイアグ`に関する記載のみがある場合は「問題あり」とする。

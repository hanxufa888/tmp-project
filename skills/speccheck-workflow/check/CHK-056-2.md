# チェック項目No. 
CHK-056-2

# チェック項目
メータからの送信信号の仕様にて、送信信号、送信値、各送信値の送信条件の記載があるか。また、下記のいずれかの仕様記載があるか。
・仕様書名
・要求ID
・MCUID
・信号値

# チェック判定仕様
## 新フォーマットの場合
1. 項目「通信仕様」で定義されている送信信号に対して、以下の確認を実施する。
 1-1:SWシート以外の場合
  項目「特別処理」に以下の全ての記載があることを確認する。すべて記載されていれば「問題なし」とし、手順2に進む。 一つでも不足している場合は「問題あり」と判断する。
   - 送信信号名
   - 送信値
   - 各送信値に対応する送信条件
   
 1-2:SWシートの場合
  項目「S*-2.ステアリングSW押下制御（メータ送信）」に以下の全ての記載があることを確認する。すべて記載されていれば「問題なし」とし、手順2に進む。  一つでも不足している場合は「問題あり」と判断する。
    -  送信信号名
    - 送信値
    - 各送信値に対応する送信条件

2.  1.で確認した送信信号に関する記載箇所について、同一記載内に下記のいずれかの指示が含まれている場合は「問題なし」と判断し、すべて含まれていない場合は「問題あり」と判断する。
  - 仕様書名
  - 要求ID
  - MCUID
  - 信号値

## 旧フォーマットの場合
1. 項目「信号名」「記号」に記載されている送信信号（章節「\*.出力」「\*.入出力」に定義された全送信信号）の各々に対して、仕様書内に以下の全ての記載があることを確認する。 すべて記載されていれば「問題なし」とし、手順2に進む。  一つでも不足している場合は「問題あり」と判断する。
  - 送信信号名
  - 送信値
  - 各送信値に対応する送信条件（当該送信信号の送信条件が章節「\*.通常制御」に記載されていれば「問題なし」、記載が無ければ「問題あり」。「\*.イニシャル処理」「\*.フェール時の処理」等、通常制御以外の章節のみに記載されている場合は代替・救済せず「問題あり」とする）
2. 1.で確認した送信信号に関する記載箇所について、同一記載内に下記のいずれかの指示が含まれている場合は「問題なし」と判断し、すべて含まれていない場合は「問題あり」と判断する。
  - 要求ID
  - MCUID
  - 信号値

# チェック項目No. 
CHK-066

# チェック項目
【機能有無判別ありの場合】
機能有無判定専用信号により判定をする場合、無⇒有、有⇒無の遷移条件が明記されているか。（機能有無判定結果を動的に切り替えられるか？）

# チェック判定仕様
 1. 機能有無判定処理の記載の有無を確認する。機能有無判定処理が記載されている場合は手順2に移行する。
 　 機能有無判定処理が記載されていない場合は、本チェックの確認は不要のため、以降の手順は実施不要とする。

 2. 機能"有"とする判定条件と、機能"無"とする判定条件の両方が、仕様書に明示的に記載されているか確認する。
    ＜各判定条件（機能"有"とする判定条件／機能"無"とする判定条件）が「明示的に記載されている」と判定する際の前提ルール＞
    - 判定は、変更された記述（差分行）単体ではなく、当該機能有無判定処理が記載された記載単位（該当する項目・章節）の全体を対象に行うこと。差分行にその判定条件が書かれていないことのみを根拠に「記載なし」と判断せず、同一の機能有無判定処理に属する他の記載（同一章節・項目内の他の行や、そこから参照される関連記載）を含めて確認したうえで、機能"有"／機能"無"とする判定条件それぞれの明示有無を判定すること。
    - 補集合推論による穴埋めを禁止する。機能"有"とする判定条件のみが記載されている場合に、その否定（例:「機能"有"条件が不成立なら機能"無"」）を根拠として、機能"無"とする判定条件が「実質的に記載されている」とみなしてはならない。仕様書に明示的に記載された判定条件のみを「記載あり」と判断する。
    - 【参照解決の必須化】機能"有"／機能"無"とする判定条件が、他の要求ID・章節・シートの記載を参照する表現で書かれている場合、その参照先を辿り、判定可能な具体条件（データラベル＋ビット／電源状態／タイマ等）に到達するまで実体化すること。参照表現を辿らず、文字列として肯定形／否定形の条件が存在することのみを根拠に「明示記載あり」と判断してはならない。また、記載内容が循環参照や自己参照になっている場合は、"記載なし"扱いにする。
    ＜上記ルールに基づく各判定条件の記載有無の組み合わせによる「問題なし」/「問題あり」判断＞
    - 機能"有"・機能"無"の両方が明示的に記載されている場合：「問題なし」と判断し、以降の手順は実施不要とする。
    - 機能"無"とする判定条件のみが明示的に記載されている場合：「問題あり」と判断し、以降の手順は実施不要とする。
    - 機能"有"とする判定条件のみが明示的に記載されている場合：手順3に移行する。
    - 両方とも明示的に記載されていない場合：「問題あり」と判断し、以降の手順は実施不要とする。

 3. 判定条件にデータラベル名の通信信号が使用されているか確認する。
    判定条件にデータラベル名の通信信号が使用されている場合は「問題あり」と判断する。
    判定条件にデータラベル名以外の判定条件が使用されている場合は「問題なし」と判断する。

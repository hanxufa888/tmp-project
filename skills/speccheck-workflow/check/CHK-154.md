# チェック項目No.
CHK-154

# チェック項目
初期化処理およびフェール処理に関する記載が、それぞれ所定の章節に記載されており、通常制御の章節へ誤って記載されていないことを確認する。

# チェック判定仕様
- 手順1～2は独立した観点のチェックである。いずれかの手順で「問題あり」となっても、残りの手順を省略せず、全手順を最後まで実施すること。
- 各手順の判断結果（問題なし/問題あり）を個別に記録し、最終判断は全手順の結果を統合して行うこと。
1. 仕様追加、変更個所が、初期値や初期化に関する記載であれば「問題あり」、記載でなければ「問題なし」とする。
2. 仕様追加、変更個所が、通信途絶、センサ異常、読出し異常などの異常処理に関する記載であれば「問題あり」、記載でなければ「問題なし」とする。

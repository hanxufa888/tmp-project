# チェック項目No. 
CHK-090-1

# チェック項目
MCUIDを追加または変更した場合、MCUID/定数名がMCUCONSTと一致しているか？

# チェック判定仕様
チェックの手順:
1. 追加、変更があったMCUIDがMET-M_MCUCONST-CSTD-\*に記載されているかを確認する。
   記載されていない場合は「問題なし」と判断、記載されている場合は手順2.を確認する。
2. 追加、変更があったMCUIDに定数名が併記されているか確認する。
   MCUIDの付近に【】で囲まれた文字列がある場合、「定数名が併記されている」と判断すること。
   併記されていない場合、手順3.を確認する。
　 併記されている場合、手順3.および手順4を確認する。
3. 追加、変更があったMCUIDについて、以下の(a)(b)を比較し、(a)のMCUIDが指す定数の用途・意味が、(b)の仕様書の使用文脈と整合しているかを確認する。
 (a) MET-M_MCUCONST-CSTD-\*の情報: 当該MCUIDの定数名（Name列）、使用している制御仕様書No.、定数選択肢の定義（Definition of constants options）
 (b) 制御仕様書側（チェック対象仕様書）の情報: 当該MCUIDが記載されている箇所の仕様内容や概要

 　判断基準:
 　(a)の定数の用途・機能領域と、(b)の使用文脈・機能領域が明らかに異なる場合は「問題あり」として判断する。
 　(a)の定数の用途・機能領域と、(b)の使用文脈・機能領域が整合している、または合理的に関連付けられる場合は「問題なし」と判断する。

4. 追加、変更があったMCUIDと併記されている定数名が、MET-M_MCUCONST-CSTD-\*に記載されているMCUIDと定数名と一致していれば「問題なし」、不一致であれば「問題あり」と判断する。

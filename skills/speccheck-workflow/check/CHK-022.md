# チェック項目No. 
CHK-022

# チェック項目
通信途絶判定後にセットする値が非アクティブ側が設定されているか。アクティブ側の値が設定されている場合、機能有無判定があるか。

# チェック判定仕様
## 新フォーマットの場合
以降の判断は各シート毎に別々に実施する。
1. 以下項目に設定されている値（以降"通信途絶判定後にセットする値"とする）が、アクティブ状態の項目「実施条件」と同じ値なら"2."へ進み、非アクティブ状態の項目「実施条件」と同じ値なら「問題なし」と判断する。但し「BZR」シートの場合は、アクティブ状態の項目「実施条件」と同じ値なら「問題あり」と判断する。("2."へ進む必要なし)
 - 項目「通信途絶判定後にセットする値"IGR-ON中(IG2-ON中)"」
 - 項目「通信途絶判定後にセットする値"IGR-OFF中(IG2-OFF中)"」
2. "通信途絶判定後にセットする値"と同じ値だった項目「実施条件」に紐づく項目「機能有無判定」に"〇"が設定されていれば「問題なし」、"×"が設定されていれば「問題あり」と判断する。

## 旧フォーマットの場合
1. 項目「途絶判定後の処理」もしくは「\*途絶判定後の制御」に設定されている値が、アクティブ状態の設定値なら"2."へ進み、非アクティブ状態の設定値なら「問題なし」と判断する。但しブザー機能に関しては、アクティブ状態の設定値なら「問題あり」と判断する。("2."へ進む必要なし)
2. 項目「途絶判定後の処理」もしくは「\*途絶判定後の制御」に設定されている値が、項目「機能有無判定」に機能有無判定処理が記載されていれば「問題なし」、記載されてなければ「問題あり」と判断する

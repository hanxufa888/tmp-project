# チェック項目No. 
CHK-021

# チェック項目
通信途絶時間の判定条件が正しい事を確認したか
（判定条件：CAN通信周期が720ms以下であれば通信途絶時間が3600msとなっているか。またはCAN通信周期が720msより大きい場合は通信途絶時間がCAN通信周期の5倍になっているか）

# チェック判定仕様
## 新フォーマットの場合
以降の判断は各シート毎に別々に実施する。
1. 項目「通信途絶判定後にセットする値」に「-」以外の値が記入されているか確認する。
　「-」以外の値が記入されている場合は手順2を確認する。それ以外の場合は「問題なし」として確認を完了する。
　
2. 項目「途絶判定時間(msec)」の値に以下"2-A"と"2-B"の大きい方の値が設定されていれば「問題なし」、そうでない場合は「問題あり」と判断する。
但し、"2-A"と"2-B"が同値の場合は「問題なし」と判定する。
なお、同一信号に対し送信周期（通信周期）が複数記載されている場合は、後述「## 同一信号に複数の送信周期（通信周期）が記載されている場合（新旧共通）」に従って判定する。
### 2-A
3600ms
### 2-B
項目「通信周期(msec)」の値を5倍し、100ms単位で切り上げした時間

## 旧フォーマットの場合
1. 変更の有った通信信号に対し、項目「通信途絶判定後の制御」に「無し」や「前回値を保持すること」の記載があるか確認する。
　「無し」や「前回値を保持すること」の記載がある場合は「問題なし」として確認を完了する。それ以外の場合は手順2を確認する。
2. 項目「判定時間」 or 項目「通信途絶判定」に記載されている時間に以下"2-A"と"2-B"の大きい方の値が設定されていれば「問題なし」、そうでない場合は「問題あり」と判断する。
但し、"2-A"と"2-B"が同値の場合は「問題なし」と判定する。
なお、同一信号に対し送信周期（通信周期）が複数記載されている場合は、後述「## 同一信号に複数の送信周期（通信周期）が記載されている場合（新旧共通）」に従って判定する。
### 2-A
3600ms
### 2-B
項目「送信周期」の値を5倍し、100ms単位で切り上げした時間

## 同一信号に複数の送信周期（通信周期）が記載されている場合（新フォーマット・旧フォーマット共通）
チェック対象の信号が、複数のメッセージラベル等により異なる送信周期（通信周期）を複数持つ場合（例：同一信号 SFT_MET が ECT1S93=1024ms と ECT1G92=1000ms の2つの送信周期を持つ）は、以下に従い判定する。
1. 記載されている送信周期（通信周期）の**各々**について、個別に"2-B"（当該周期の値を5倍し、100ms単位で切り上げした値）を算出し、各周期における「設定すべき値」（"2-A"=3600ms と 当該"2-B" の大きい方）を求める。
2. 通信途絶判定時間（項目「判定時間」／「通信途絶判定」／「途絶判定時間(msec)」等）が、**各送信周期に対応して複数記載されているか**を確認する。
   - 各送信周期に対応する通信途絶判定時間が個別に記載され、各々が当該周期における「設定すべき値」と一致していれば「問題なし」。
   - いずれかの周期に対応する通信途絶判定時間が記載されていない、または記載値が当該周期の「設定すべき値」と一致しない場合は「問題あり」と判断する。
3. 単一の通信途絶判定時間しか記載されていない場合は、その記載値が**全ての送信周期における「設定すべき値」を満たしているか**（＝各周期で算出した値がすべて当該単一記載値と一致するか）を確認する。各周期で算出される値が異なり、単一記載値がその一部の周期しか満たさない場合は「問題あり」と判断する。
4. 最も長い送信周期のみに合わせてよい、worst-case（最長周期）で包絡してよい、といった**技術的推論で複数周期間の不一致を解消してはならない**（規則に明記のない読み替え・簡略表記の推論を行わない）。複数周期の扱いに関する記載が仕様書側に不足し機械的に判定できない場合は「要確認」とする。

# チェック項目No. 
CHK-043-2

# チェック項目
【個別のドラモニ仕様書の変更時】
ドラモニ共通仕様書の記載内容と、個別のドラモニ仕様書と記載内容に不整合がないかを確認する

# チェック判定仕様
1. チェック対象仕様書の仕様変更点に関する内容が、MET-M_DM-\*に記載されているか確認し、記載されていれば手順2へ進む。記載されていなければ「問題なし」と判断する。
2. チェック対象仕様書の仕様変更点と、MET-M_DM-\*の記載内容に矛盾または意味の相違があれば「問題あり」と判断し、なければ「問題なし」と判断する。
　矛盾・相違の確認時は、以下を実施すること。
  - MET-M_DM-*の該当記載に関連する個別ドラモニ仕様書名（※1）を特定・出力する。
　※1：個別のドラモニ仕様書とは、MET-M_DM-\*の章節「\*.概要」に記載されている仕様書を指す。
  - 個別ドラモニ仕様書名を特定・出力する際はバリまで出力する。バリの記載がなければバリは出力しなくてよい。
  - 当該個別ドラモニ仕様書名がチェック対象仕様書名と同一かを確認する。

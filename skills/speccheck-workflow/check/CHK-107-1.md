# チェック項目No. 
CHK-107-1

# チェック項目
【ゲージ表示仕様の場合】
バー表示/アナログ表示/指針表示/ゲージの信号値に対して、表示が上下限を超える場合の仕様が記載されているか。または、表示条件の信号値は、全bit分の仕様が記載されているか。

# チェック判定仕様
## 新フォーマットの場合
- 確認は、特定の基本画面No.単位に閉じず、**対象仕様書内の全基本画面（全ての基本画面No.）を横断して**行う。対象のバー/アナログ/指針/ゲージの表示条件信号について、仕様書全体での記載を確認する。
- 確認範囲は、対象仕様書内の以下の「実施条件」「特別処理」の全体とする（基本画面No.をまたいで合算してよい）。
  - Variable_MID「5-1.基本画面の表示 要求」の全行の項目「実施条件」
  - Variable_MID「5-3-\*.各表示エリアの表示 要求」配下の全「G\*-1.グループ\* 表示要求」の項目「実施条件」
  - Detailed Spec2「11-\*.基本画面No.\*」の項目「特別処理」
- 上記の確認範囲（全基本画面の合算）内で、バー表示/アナログ表示/指針表示/ゲージの信号値に対して、表示値が上下限を超えた場合の仕様、または表示条件の信号値の全bit分の仕様が記載されていれば「問題なし」と判断し、いずれも記載されていなければ「問題あり」と判断する。
- 注記：ある基本画面が単一のビット値（例：センサ異常値のみ）でしか表示条件信号を参照していない場合でも、他の基本画面を含む全基本画面を合算して当該表示条件信号の全bit分の仕様（または上下限超過時の仕様）が記載されていれば「問題なし」と判断する（網羅性は全基本画面を横断して確認し、当該表示条件信号を扱う基本画面の記載を合算する）。

## 旧フォーマットの場合
- 章節「\*.通常制御」に、 バー表示/アナログ表示/指針表示/ゲージの信号値に対して、表示値が上下限を超えた場合の仕様、または表示条件の信号値の全bit分の仕様が記載されていれば「問題なし」と判断し、いずれも記載されていなければ「問題あり」と判断する。

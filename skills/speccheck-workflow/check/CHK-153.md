# チェック項目No.
CHK-153

# チェック項目
数値データのリセット処理の必要性を確認する。他ECU受信値をそのまま表示するだけのデータに対して、不要なリセット処理を定義していないか。

# チェック判定仕様
## 新フォーマットの場合
1. 仕様追加、変更個所に数値データに対するリセット処理があるかを確認し、なければ「問題なし」としチェック終了、あれば手順2を確認する。
2. リセット処理の記載全体から、リセット処理の対象となる信号を漏れなく列挙する（リセット条件に用いる信号は含めない）。
3. "2."で列挙した信号が、"Variable_MID"シートの項目「通信仕様」の"In/Out"にて、"Out"（出力信号）と定義されていれば「問題なし」、"In"（入力信号）と定義されていれば「問題あり」と判断する。

## 旧フォーマットの場合
1. 仕様追加、変更個所に数値データに対するリセット処理があるかを確認し、なければ「問題なし」としチェック終了、あれば手順2を確認する。
2. リセット処理の記載全体から、リセット処理の対象となる信号を漏れなく列挙する（リセット条件に用いる信号は含めない）。
3. "2."で列挙した信号が、章節「\*出力」に記載されていれば「問題なし」、章節「\*.入力」に記載されていれば「問題あり」と判断する。

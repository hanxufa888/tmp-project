# チェック項目No. 
CHK-014-1

# チェック項目
【CAN信号の変更がある場合のみ】
CAN信号の標準送受信登録はできているか？
仕様書に記載されるメッセージラベル／データラベル名／がDMSと一致しているか？
（含、定数仕様作成の際の車担へのメッセージ、Detailed Spec.）

# チェック判定仕様
## 新フォーマットの場合
1. DMSファイル内のシート有無確認
 項目「データラベル名」を含むシートがDMSファイル内に存在することを確認する。
 存在しない場合は「問題あり」とし、存在する場合はチェックの手順2以降の確認を当該シート内で行う。
 
2. データラベル名の確認
 項目「データラベル名」の記載内容が、チェックの手順1で検出したDMSファイルのシートの項目「Data Label」の記載内容と一致するか否かを確認する。
 一致していればデータラベルの確認結果を「問題なし」、不一致であればデータラベルの確認結果を「問題あり」とする。

3. メッセージラベルの確認
 項目「メッセージラベル」の記載内容とチェックの手順1で検出したDMSファイルのシートの項目「Message  Label」の記載内容と一致するか否かを確認する。
 一致していればメッセージラベルの確認結果を「問題なし」、不一致であればメッセージラベルの確認結果を「問題あり」とする。

## 旧フォーマットの場合
1. DMSファイル内のシート有無確認
 項目「記号」と項目「ビット名」を含むシートがDMSファイル内に存在することを確認する。
 存在しない場合は「問題あり」とし、存在する場合はチェックの手順2以降の確認を当該シート内で行う。

2. データラベル名の確認
項目「記号」と項目「ビット名」の記載内容が、チェックの手順1で検出したDMSファイルのシートの項目「Data Label」の記載内容と一致するか否かを確認する。
 一致していればデータラベルの確認結果を「問題なし」、不一致であればデータラベルの確認結果を「問題あり」とする。
3. メッセージラベルの確認
  項目「メッセージラベル」の記載内容とチェックの手順1で検出したDMSファイルのシートの項目「Message  Label」の記載内容と一致するか否かを確認する。
  一致していればメッセージラベルの確認結果を「問題なし」、不一致であればメッセージラベルの確認結果を「問題あり」とする。

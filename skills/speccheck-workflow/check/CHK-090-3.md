# チェック項目No. 
CHK-090-3

# チェック項目
CONTBUZZ仕様書に要求IDを追加した場合、元仕様書と整合が取れているか？

# チェック判定仕様
1. 追加された要求IDと同一行の項目「メータ仕様書No（参考）」に記載された仕様書内に当該要求IDの記載があるかを確認する。記載が無い場合は「問題あり」と判定し、ある場合は手順2を確認する。
2. 追加された要求IDと同一行の項目「ブザー吹鳴状態　トヨタ／レクサス」、「ブザー音　周波数(Hz)」、「断続吹鳴　周期(sec)」の内容が、「メータ仕様書No（参考）」に記載された仕様書内の記載内容と一致してるかを確認する。一致していれば「問題なし」、一致していなければ「問題あり」と判定する。
但し、「メータ仕様書No（参考）」に記載された仕様書が旧フォーマットの場合に限り、
「ブザー吹鳴状態　トヨタ／レクサス」、「ブザー音　周波数(Hz)」、「断続吹鳴　周期(sec)」に該当する記載内容がない場合は「問題なし」と判定すること。

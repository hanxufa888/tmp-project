# チェック項目No. 
CHK-025-1

# チェック項目
機能有無判定有りの場合、条件式や命令文がCAN信号の通信周期*2.1且つ2回連続受信となっているか

# チェック判定仕様
機能有無判定について、以下の1.と2.を**両方**満たす場合のみ「問題なし」とし、いずれか一方でも満たさない場合は「問題あり」と判断する。

1. 機能有無判定の成立条件に、機能有無判定信号を「2回連続受信」した場合に機能有無「有り」判定となる旨が記載されていること。
2. 上記2回連続受信の**時間窓（何msの時間内で2回連続受信するか）が仕様書に明記**されており、かつその値が機能有無判定信号の「通信周期×2.1（切上げし100msec単位）」となっていること。

## 判定における絶対制約（時間窓明記の必須化）
- 時間窓は「◯ms（以内）」等の**具体的な時間値**として仕様書に明記されている必要がある。時間窓の数値記載が無い場合は、たとえ「連続2回受信」「同じ値を連続2回受信」等の記載があっても、時間窓の要件不足として**問題あり**と判断すること。
- 「連続」「連続受信」等の語義から時間窓（通信周期×2.1）が実質的に満たされると**推論・補完して救済してはならない**。時間窓の数値記載の有無で機械的に判定する。
- 明記された時間窓の値が、機能有無判定信号の「通信周期×2.1（切上げし100msec単位）」と一致しない場合も「問題あり」と判断する。
- 時間窓の明記の有無は変更後仕様書の記載自体で確定できるため、情報不足を理由に「要確認」とはせず、「問題あり」または「問題なし」のいずれかで判定すること。

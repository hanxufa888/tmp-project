# チェック項目No. 
CHK-060-3

# チェック項目
 実施条件、適用条件、終了条件が、仕様書名、要求ID、MCUID、信号値のいずれかで記載されているか。
「等」「T.B.D.」が条件に含まれていないか。

# チェック判定仕様
対象個所の変更点について、以下の確認を行う。
1. 変更内容が仕様書名、要求ID、MCUID、信号値のいずれかで記載されていれば「問題なし」, いずれも記載されていなければ「問題あり」と判断する。
2. 変更箇所に`等`、`T.B.D.`が記載されていれば「問題あり」、記載されていなければ「問題なし」と判断する。

## 判定における絶対制約
- 判定は、変更箇所（差分）の記載それ自体に、仕様書名／要求ID／MCUID／信号値の形式が含まれているか否かで機械的に行うこと。
- 変更箇所に複数の条件が含まれる場合は、各条件を個別に評価し、1つでも上記4形式のいずれでも一意特定されていない条件があれば、その時点で「問題あり」と判断すること。
- 自然言語の状態表現・画面名・機能名・モード名等で記載され、上記4形式のいずれでも一意特定されていない条件について、「他章節・他仕様書・参照先に特定根拠が存在しうる」と推論して当該条件を補完・救済してはならない。変更箇所自体に4形式の記載が無い条件は「問題あり」とする。
- 上記4形式の有無は変更箇所の記載のみで確定できるため、情報不足を理由に「要確認」と判定することを禁止する。本チェックの判定結果は「問題あり」または「問題なし」のいずれかとすること。

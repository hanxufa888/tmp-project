# チェック項目No. 
CHK-089-1

# チェック項目
以下の項目を変更する場合、要求IDを新規取得したか？

CONTDISPに関わる項目：
・マスターコーションランプ・ブザー
・HUD割り込みの有無
・情報種類
・優先度（回避余裕・重大度・遭遇度合）
※上記以外の項目に関しては、適宜確認すること

# チェック判定仕様
## 新フォーマットの場合
- 詳細項目「M/Cランプ連動」、「M/Cブザー有無」、「情報種類」、「優先度」のいずれかが変更されているが、詳細項目「要求ID」が変更されていない場合は「問題あり」判断すること。

## 旧フォーマットの場合
- 詳細項目「マスターコーションブザー吹鳴」、「情報クラス」、「優先度」のいずれかが変更されているが、詳細項目「要求ID」が変更されていない場合は「問題あり」判断すること。

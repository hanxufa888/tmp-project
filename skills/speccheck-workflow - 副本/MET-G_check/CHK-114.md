# チェック項目No.
CHK-114

# チェック項目
仕様の変更箇所と、同仕様書内の他の仕様記載箇所にて、記載内容に不整合はないか（変更漏れ／追加漏れ／削除漏れ等）。

# チェック判定仕様
## チェックの手順
仕様変更個所が「変更」、「削除」の場合、は"A"の手順で確認する。
仕様変更個所が「追加」の場合は、"B"の手順で確認する。 

### 手順A
  1. 仕様変更個所の変更前の記載に対し、同一もしくは類似する記載を変更後仕様書内の全ての項目から抽出する。
    同一もしくは類似する記載がある場合は2.を確認し、同一もしくは類似する記載が無い場合は「問題なし」と判断する。
  2. 同一もしくは類似する記載に対し、変更が必要な個所が無いかを確認し、変更が必要な個所があれば「問題あり」、変更が必要な個所が無ければ「問題なし」と判断する。

### 手順B
  1. 追加された項目（信号名、画面名、要求ID等の識別子）や内容を特定する。 
  2. 変更後仕様書内で、追加された項目と同種の既存項目（例：同じ章内の他の信号、同じテーブル内の他の行）が、どの章節・テーブルに記載されているかを網羅的に列挙する（＝セット記載構造の把握）。 
  3. 追加された項目が、既存の同種項目と同じセット記載構造の全箇所に記載されているかを確認する。 
  4. 記載がない箇所がある場合、その箇所への追加が不要である合理的理由（例：信号種別の違いにより対象外）があるかを確認する。合理的理由がなければ「問題あり」と判断する。

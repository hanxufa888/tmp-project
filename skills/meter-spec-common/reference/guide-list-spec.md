# 一覧系仕様書共通知見
## MET-M_MCUCONST-CSTD-
### 仕様の位置づけ
- 本仕様書は、各仕様書で設定された定数情報(各車両ごとに設定される値の情報)をまとめた一覧仕様書である。
- MCUID毎に定数情報が定義される。

### 仕様内の有効/無効情報
- 仕様書の有効情報は以下箇所とし、他箇所は無効情報として扱うこと。
  - 有効シート： "MCUCONST(編集用 For Editing)"
  - "MCUCONST(編集用 For Editing)"シート内の有効項目： "ユニークID", "Name", "【TMC設計用】使用している制御仕様書No.", "定数選択肢の定義", "出荷時定数値", "Type", "LSB/Prec", "Ofs", "単位", "Min", "Max", "【TMC車担用】定数適合方法"

### 仕様の読み方
- "MCUCONST(編集用 For Editing)"シートの読み方は"MCUCONST_rules"シート内の"３．"MCUCONST(編集用 For Editing)"シートの説明 / 3. Description of "MCUCONST(編集用 For Editing)" sheet"章を参照すること。
- 項目"ユニークID"が空欄の行は無効情報として扱うこと。
- 各行に定義されたユニークID(MCUID)を使用している仕様書は項目"【TMC設計用】使用している制御仕様書No."に記載される。

## MET-M_CONSTSORT-CSTD-
### 仕様の位置づけ
- 本仕様書は制御仕様書内で"車両適合定数一覧を参照"と書かれた定数仕様について、その内容(設定値/参照先仕様書)を指示する仕様である。
- 他制御仕様書との関連は"定数仕様書一式_概要説明"シート内の"1．概要"章を参照すること。

### 仕様内の有効/無効情報
- 仕様書の有効情報は以下箇所とし、他箇所は無効情報として扱うこと。
  - 有効シート： "CONSTSORT"
  - "CONSTSORT"シート内の有効項目： "制御仕様書名(メインバリまで書く)", "章", "題名", "定数名", "定数記号", "定数選別結果"

### 仕様の読み方
- "定数仕様書一式_概要説明"シートの"2．「定数選別結果MET-M-CONSTSORT」の役割"章を参照すること。
- "CONSTSORT" シートでは、項目"制御仕様書名"と"章"と"題名"により対象箇所を特定し、記載されている"定数名"もしくは"定数記号"を"定数選別結果"に従って解釈する。

## MET-M_CONTDISP-CSTD-
### 仕様の位置づけ
- 本仕様書は、各仕様書で定義される警告アドバイス表示(割り込み表示)に対して、要求ID毎に表示優先度や詳細仕様を定義する。

### 仕様内の有効/無効情報
- 仕様書の有効情報は以下箇所とし、他箇所は無効情報として扱うこと。
  - 有効シート： "一覧", "電源状態", "工場検査モード", "輸送時エアコンモード", "提案サービス", "Fuel Lid 待機画面", "Door Unlock", "MM連携", "カスタマイズ設定要求", "ONS"
  - 上記シート内の有効項目： "警告／アドバイス表示一覧", "マスターコ―ション-ランプ○点灯", "マスターコ―ション-ブザー○吹鳴", "ソフトSWを伴う割込みメッセージ", "ガイドSWUIタイプ", "情報種類", "描画機能無しHUD車両HUD割込み〇と●と△が対象", "メッセージタブ表示対象", "優先度", "参考情報-メータ仕様書No（参考）", "MMメッセージ表示対象"

### 仕様の読み方
- 各シートの項目"警告アドバイス表示"は、表の上から順に表示の優先度が高いものとする。
- 項目"メータ仕様書No（参考）"は、参照関係のある制御仕様書が記載され、要求IDで本仕様書と各仕様書の情報を紐づける。
- 項目"メッセージタブ表示対象"の"〇"(格納)/"×"(格納しない)設定の考え方は、"考え方"シートの"■メッセージタブ格納の考え方"章を参照すること。
- "ソフトSWを伴う割込みメッセージ"とは、Yes/NoのようなユーザーにSW操作を促す表示が存在するメッセージのことである。
- "ガイドSWUIタイプ"の定義は、"MET-M_STSW-CSTD-0-\*-\*-C\*-\*_添付資料_GUI表示制御仕様.xlsx"の"2.2割込みMSG表示"シートを参照すること。

## MET-M_CONTBUZZ-CSTD-
### 仕様の位置づけ
- 本仕様書は、各仕様書で定義されるブザー仕様に対して,要求ID毎に表示優先度や詳細仕様を定義する。
- 各ファイルの位置づけは以下の通り。
 - "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*.doc"：全ブザー共通の仕様を定義する。
 - "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料1）.xlsx"：本紙"MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*.doc"から参照され、各種ブザーの優先順位や詳細な吹鳴仕様を定義する。
 - "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料2）.pdf"：サウンドファイル(音源ファイル)の変更時の変更内容/変更理由とサウンドファイルの命名ルールを記載する。
 - "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料3）.xlsx"：サウンドファイル名と音圧低減率等が定義されている。

### 仕様内の有効/無効情報
- 仕様書の有効情報は以下箇所とし、他箇所は無効情報として扱うこと。
  - 有効ファイル："MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*.doc"
  - 有効ファイル："MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料1）.xlsx"
    - 有効シート："BZR"
  - 有効ファイル："MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料3）.xlsx"
    - 有効シート："サウンドファイル名及び音圧低減率", "クリアランスソナー", "ターン", "同時吹鳴時の出力"

### 仕様の読み方
- "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料1）.xlsx"の"BZR"シートの読み方は"凡例"シートを参照すること。
- "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料1）.xlsx"の"BZR"シートの項目"メータ仕様書No（参考）"には、参照関係のある制御仕様書が記載され、要求ID(ID)で本仕様書と各仕様書の情報を紐づける。
- "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料1）.xlsx"と"MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料3）.xlsx"の紐付けは、各々の仕様書の項目"ブザー名称"で行うこと。
- "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料1）.xlsx"の項目"サウンドファイル（サウンドファイルの適用や追番については定数仕様書に従うこと）-トヨタ"と、"MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料3）.xlsx"の項目"サウンドファイル-トヨタ ※1"は同義項目である。
- "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料1）.xlsx"の項目"サウンドファイル（サウンドファイルの適用や追番については定数仕様書に従うこと）-レクサス"と、"MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料3）.xlsx"の項目"サウンドファイル-レクサス ※1"は同義項目である。
- "MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料1）.xlsx"に添付資料3への参照記載がある場合は、"MET-M_CONTBUZZ-CSTD-\*\*\*\*-C\*（添付資料3）.xlsx"の"サウンドファイル名及び音圧低減率"シートの該当項目を参照すること。

## MET-M_REMWAR-CSTD-1-
### 仕様の位置づけ
- メータでは各システムの異常・故障を、規定された条件に基づいて判定し、条件成立時に対応するリモートウォーニング信号をCAN通信で送信する。
- 本仕様書は、メータから送信するリモートウォーニング信号の送信条件仕様を定義する。
- 各ファイルの位置づけは以下の通り。
 - "MET-M_REMWAR-CSTD-1-\*\*-\*-\*.xlsx"：リモートウォーニング送信信号の条件や送信値等の仕様が定義される。
 - "(DMS(In))MET-M_REMWAR-CSTD-1-\*\*-\*-\*.xlsx"：リモートウォーニング送信判定のためにメータに入力されるCAN信号に関する情報が定義される。
 - "(DMS(Out))MET-M_REMWAR-CSTD-1-\*\*-\*-\*.xlsx"：メータから送信するリモートウォーニングのCAN信号に関する情報が定義される。

### 仕様内の有効/無効情報
- 仕様書の有効情報は以下箇所とし、他箇所は無効情報として扱うこと。
  - 有効シート： "【19PF】RW_送信信号対応表", "入力信号規定"

### 仕様の読み方
- "MET-M_REMWAR-CSTD-1-\*\*-\*-\*.xlsx"の"【19PF】RW_送信信号対応表"シートにリモートウォーニング信号の各種仕様が定義される。
  - 以下の項目はリモートウォーニング信号の情報として解釈する。
    - Msg.inf.
    - メータ仕様-Data Label
    - メータ仕様-データ定義
  - 以下の項目はリモートウォーニング信号を送信するための条件として解釈する。
    - メータ仕様-”１”送信条件　(以下のAND)
  - 以下の項目はリモートウォーニング信号の対象システムの情報として解釈する。
    - メータ仕様-システム名
    - メータ仕様-故障・異常内容
  - 項目"メータ仕様-参照メータ仕様書"には、参照関係のある制御仕様書が記載され、項目"メータ仕様-Data Label"で本仕様書と各仕様書の情報を紐づける。    
- "MET-M_REMWAR-CSTD-1-\*\*-\*-\*.xlsx"の"入力信号規定"シートは、以下が定義された信号一覧シートである。
  - 項目"Data Label"に"【19PF】RW_送信信号対応表"シートの項目"メータ仕様-”１”送信条件　(以下のAND)-判定条件 (以下のOR)"に記載されている信号が全て定義される。
  - 項目"対象リモートウォーニングData Label"に"【19PF】RW_送信信号対応表"シートの項目"メータ仕様-Data Label"に記載されている信号が全て定義される。

### その他知見
- "リモートウォーニング仕様"、"RW仕様"と記載されることもある。
- リモートウォーニング信号は"RW信号"と記載されることもある。

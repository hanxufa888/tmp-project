## 共通
### 共通用語
- "GFX"は"グラフィック"という意味である。

### 仕様内の有効/無効情報
- 以下記載は無効情報として扱うこと。
  - セルの背景色が灰色の個所。
  - "×"の図（オブジェクト）が重ねて記される個所。
    - 無効範囲は、"×"オブジェクトが覆う（重なる）範囲内とし、その範囲内の図・文字・表・セルは配下も含めて全て無効とする。
  - "TBD（T.B.D）"の図（オブジェクト）の下に記される図や文字。
  - "△+数字"の文字列（変更履歴符号であるため）。
    - ただし、無効情報となるのは"△+数字"の符号そのもののみである。"△+数字"に紐づく文字列・記載内容は無効情報ではなく、有効情報として扱うこと。
  - 取り消し線（打ち消し線）が引かれた文字・記載（章節見出し・表のセル・図中文字を含む）。


## MET-G_T_SCREEN-CSTD-A0-
### 仕様の位置づけ
- "Common"シートの章節「1.概要」を参照とする。
- 表示コンテンツ内の表示部品や条件は、本仕様から他仕様書（「表示対象仕様書」）参照となっており、
  他のMET-G系の仕様書と比較し本仕様書は上位の仕様書として位置づく。
### 仕様の読み方
- 章節「1. Windowレイアウト定義」の図（オブジェクト）と「2. コンテンツ定義」の表は、どの位置にどのコンテンツを表示するかが紐づけて記載される。
  章節「2. コンテンツ定義」には、図（オブジェクト）内のレイアウト、エリア、コンテンツがどの電源状態で表示可能かが記載される。
  表示可能電源状態に記載された3桁の数値は、「1.Windowレイアウト定義」の図に対する見出し文字列内の数値と紐づけて記載される。
- 「2. コンテンツ定義」の表内のセル記号は、"〇"＝表示可（表示可能）、"×"＝表示不可として扱うこと。
- 「2. コンテンツ定義」表の「表示可能電源状態」列は、列群名は"電源状態"だが、配下は多段ヘッダ〔電源状態(IG OFF/IG ON) → レイアウト・状態名 → Normal/Int → 3桁レイアウト番号〕で構成される。1つのデータ列を特定するには、これら全段を縦に読むこと。実質は「各レイアウト状態での表示可否」を示す表である。
- 上記の「3桁数値↔Windowレイアウト定義図の見出し数値の紐づけ」ルールは、MET側（"【MET】Windowレイアウト-コンテンツ定義"シート）専用の構造である。HUD側（"【HUD】Windowレイアウト-コンテンツ定義"シート）はWindowレイアウト定義図も3桁番号も持たず、「表示可能電源状態」は IG OFF / IG-ON の2列のみである。HUDのレイアウトは"【HUD】画面遷移図"「2. 割り込み画面レイアウト」を参照すること。
- "【MET】画面遷移図"シート及び"【HUD】画面遷移図"シートの"記号"は図（オブジェクト）内に紐づき、
  "記号"に対応した遷移条件を満たす場合に図（オブジェクト）内の"記号"が書かれている矢印先にある画面に遷移する。
- 表の読み方について、表の行見出しが空白の場合、その行の上の行見出しと同じと考えること。
- 表の項目"要求ID"欄に記載されている文言は、仕様書名とは見なさず必ず要求IDと見なすこと。
　例：下記表の"MET-G_T_SCREEN-CSTD-A0-17"は仕様書名とも読み取れるが、項目欄に"要求ID"と記載されているので、仕様書名ではなく要求IDと見なすこと。

    各列は「対象仕様書」の"TT"シートを転記元とし、"対象シート"＝TTシート名、"対象章番号"＝TTシート内の章番号、"説明"＝当該表示の説明、を意味する。（以降の表示エリア列（●/ー）の読み方は他の機能シートと同じ。）
- 対象仕様書：「基本画面 No.」、「グループ No.」、「表示変化グループ」、「文言詳細」の転記元の仕様書名が記載される。

- MAIN、C-INTERRUPT、S-INTERRUPT、CONSTLEFT、CONSTRIGHT、CCSET：HUDのエリア名が記載される。
  エリア名は、"MET-G_T_SCREEN"仕様書の"【HUD】Windowレイアウト-コンテンツ定義"シートの章節「2. コンテンツ定義」の「表示レイアウト」列に該当する。
- 表で"●"となっている個所は表示対象となり、"ー"（ハイフン）となっている個所は表示対象外を意味する。
- "INTERRUPT"欄の"●"の意味：
  割込み画面の中で表示が可能であるという意味であり、この表示要求により割込み表示を行うという意味ではない。
  割込み表示条件は"MET-G_TACCSWSG2-CSTD-A0"の「割込み表示条件」を参照すること。
